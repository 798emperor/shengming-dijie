# 生命递接 · 上线步骤

这个文件夹里有两个文件,传上去就能用:

| 文件 | 作用 |
|---|---|
| `index.html` | 演示本体。别人扫码打开的就是它。 |
| `scan.html` | 扫码卡。打开它会**自动生成**指向本站的二维码,直接打印即可。 |

两个文件都是单文件、不依赖网络,不加载任何外部字体、图片或脚本。

---

## 一、传到 GitHub Pages

1. 打开 <https://github.com>,注册并登录。

2. 右上角 **+** → **New repository**
   - **Repository name** 填 `shengming-dijie`(名字会出现在网址里,用英文)
   - 选 **Public**(必须是公开的,私有仓库发布不了网页)
   - 点 **Create repository**

3. 在新仓库页面点 **uploading an existing file**,把 `index.html` 和 `scan.html` 两个文件拖进去,然后点 **Commit changes**。

4. 仓库顶部点 **Settings** → 左边栏点 **Pages**
   - **Source** 选 `Deploy from a branch`
   - **Branch** 选 `main`,文件夹选 `/ (root)`
   - 点 **Save**

5. 等 1–2 分钟,刷新 Pages 页面,顶部会出现网址,形如:

   ```
   https://你的用户名.github.io/shengming-dijie/
   ```

   这就是别人要访问的地址。

6. 打开 `https://你的用户名.github.io/shengming-dijie/scan.html`,
   二维码会自动指向上面那个网址。用浏览器打印这一页,就是一张扫码卡。

---

## 二、确认一下

上线后建议自己先验一遍:

- 用**手机**扫一下 `scan.html` 上的二维码,看能不能打开演示
- 换一台**没登录过任何账号**的手机再扫一次,确认陌生人也能打开
- 手机上打开后,人体图上的器官能不能点开

---

## 三、国内访问慢的话

GitHub 在国内有时打不开或很慢。如果现场要用,建议改用 **Gitee**(码云),流程几乎一样:

1. 打开 <https://gitee.com> 注册登录
2. 新建仓库,选公开
3. 上传同样这两个文件
4. 仓库页面 → **服务** → **Gitee Pages** → 点 **部署**
5. 得到网址形如 `https://你的用户名.gitee.io/shengming-dijie/`

> Gitee 首次开启 Pages 需要实名认证。

`scan.html` 不用改,放到哪个域名下,二维码就自动指向哪里。

---

## 四、以后要改内容

两个文件都是纯 HTML,用记事本或 VS Code 就能改:

- **改器官的数据和故事**:在 `index.html` 里搜 `var DATA =`,每个器官一条,
  `n1`/`l1` 是第一个大数字和它的说明,`n2`/`l2` 是第二个,`story` 是故事段落。
- **改统计日期**:搜 `var ASOF =`。
- **改首页三个数字**:搜 `var targets =`。
- **改扫码卡上的文字**:在 `scan.html` 里直接改 `<h1>` 和 `class="lede"` 那段。

改完重新上传覆盖即可,网址不变,二维码也不用重做。
